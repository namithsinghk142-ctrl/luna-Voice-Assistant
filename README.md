# 🌙 Luna AI

A futuristic AI voice assistant built using Python, Flask, HTML, CSS and JavaScript featuring voice recognition, smart commands, YouTube music control, memory system, calculator, real-time responses and a cinematic sci-fi UI.

---

# 🚀 Features

- 🎤 Voice Recognition
- 🌐 Smart Google Search
- 🎵 YouTube Music Control
- 🧠 Memory System
- 🧮 Smart Calculator
- 😂 Jokes & Fun Responses
- 🎬 Movie Recommendations
- 🎮 Game Suggestions
- ⏰ Real-Time Clock
- ⚡ Fast Flask Backend
- 🌌 Futuristic Cinematic UI
- 🔊 AI Voice Responses

# ▶️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/yourusername/luna-ai.git
```

---

## 2. Open project folder

```bash
cd luna-ai
```

---

## 3. Install requirements

```bash
pip install flask flask-cors
```

---

## 4. Run the app

```bash
python app.py
```

---

## 5. Open in browser

```text
http://127.0.0.1:5000/
```
